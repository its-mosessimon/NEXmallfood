Prototype directory — starter dataset of outlets sourced from the official NEX store directory (nex.com.sg), Aug 2026. Stall numbers, reservation lines and hours can change — please confirm with the outlet before visiting. Add more outlets by editing the OUTLETS array in this file. The wheel always spins across whatever's currently filtered above — narrow it down (e.g. Japanese + Halal) before you spin. "⭐ Google Reviews" and "🛵 Order on Grab" are live search links, not stored ratings or delivery flags — they always show whatever Google/Grab have right now, so they can't go stale like a hardcoded number would. Grab is hidden for outlets that typically use their own delivery app in Singapore (Starbucks, Coffee Bean). The star-rating preview on each card is live too: add your own free Google Places API key to the GOOGLE_PLACES_API_KEY constant near the top of the script to switch it on — until then, each card shows a "tap to check" link instead of a guessed number.
